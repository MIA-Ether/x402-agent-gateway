# Architecture Decisions

## ADR-001

Hedera is the primary MVP payment network.

## ADR-002

HTTP 402 remains the payment challenge mechanism.

## ADR-003

Facilitator owns payment verification and proof issuance.

## ADR-004

Gateway never holds Agent private keys.

## ADR-005

USDC is the only MVP payment asset.

## ADR-006

USDC uses 6-decimal integer base units internally.

## ADR-007

The Graph is an agent decision dependency.

## ADR-008

SSE is the MVP frontend event transport.
